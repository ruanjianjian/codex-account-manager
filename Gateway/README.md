# Codex Accounts local gateway

Codex-only HTTP/SSE routing helper, implemented in Go with klauspost/compress for native zstd requests. Design inspired by [yetone/Magpie](https://github.com/yetone/magpie) (MIT): account pools, session affinity and fallback before content is emitted. This helper is independently implemented; it does not vendor Magpie source or its multi-provider desktop integration.

The app exports short-lived access tokens only to a 0600 pool file within its private 0700 directory. OAuth refresh tokens stay with the existing credential owner. The helper never calls Keychain, discovers other applications' accounts, refreshes OAuth tokens, edits Codex files or consumes reset credits.

Only loopback clients with a per-install random bearer key or an exact, unexpired connected-account token may connect. Browser requests are refused. The only production upstream is `https://chatgpt.com/backend-api/codex`; redirects are never followed. Private bounded logs contain timestamps, session IDs, slot IDs/status/token counts only. Quota failures cool accounts down; text/tool output is never automatically replayed. Account-bound encrypted history cannot move between accounts; unknown sealed history requires explicitly choosing its original account or a new conversation. Session affinity is saved in a private file and reused after restart. Native legacy conversations with sealed history initially retain the authenticated original account.

`go test -race ./...` and `go build -trimpath -o ../.build/gateway/AccountsGateway .`. The app retains the built-in OpenAI provider and sets openai_base_url, so native old and new conversations use the gateway after restarting Codex. It preserves service_tier (Fast). The first beta provider table remains for conversations created on that version. Official client-side quota blocking still applies to native mode; sealed history cannot be moved to a different account to bypass it. Keep the app running while using the gateway. No claim of seamless recovery in an already-streaming turn.
